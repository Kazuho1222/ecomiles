# EcoMiles（エコマイルズ）要件定義書

## 1. プロジェクト概要

### 1.1 目的
本プロジェクトは、車などの使用による排気ガスの削減、地球温暖化抑制、環境改善を目的とし、自転車走行、ウォーキング、ランニングなどの環境に優しい移動手段を奨励するウェブアプリケーションを開発する。

### 1.2 背景
地球温暖化や大気汚染などの環境問題が深刻化する中、個人の行動変容を促進するインセンティブシステムが必要とされている。本サービスは、日常的な移動手段の選択に影響を与え、環境負荷の低い移動手段の利用を促進することを目指す。

### 1.3 概要
Stravaと連携し、ユーザーのアクティビティデータを取得。移動距離に応じてポイントを付与。ランキング・バッジ・環境貢献指標（CO2削減量、地球寿命延長など）として可視化し、ユーザーのモチベーションを維持する。

## 2. 機能要件

### 2.1 基本機能
1. **Strava連携機能**
   - ユーザーはStravaアカウントとの連携を行うことができる
   - 連携後、ライド、ウォーキング、ランニングのアクティビティデータを自動または手動で同期する

2. **ポイント付与機能**
   - アクティビティの距離に応じてポイントを付与する
   - 付与レート
   	- 🚶 ウォーキング → 1km = 1pt
   	- 🏃 ランニング → 1km = 1.5pt
   	- 🚴 自転車 → 1km = 0.5pt
   - **上限**: 1アクティビティにつき最大100pt
   - ポイントの履歴や合計を表示する

3. **可視化機能（ダッシュボード）**
   - **リアルタイム指標**: 獲得ポイント、CO2削減量(kg)、地球寿命延長(秒/μ秒)、守った氷の量(kg)、杉の木換算(本)、スマホ充電回数、LED点灯時間
   - **アクティビティ・カレンダー**: 過去6ヶ月の活動頻度をヒートマップ形式で表示
   - **アクティビティ履歴**: 同期済みデータのリスト表示（ページネーション対応）
   - **みんなの貢献**: 全ユーザーの総移動距離、総アクティビティ数、総CO2削減量を表示

4. **ユーザー管理機能**
   - Clerkによる認証（Google連携、メールアドレス認証）
   - プロフィール表示（名前、アバター画像）

5. **ランキング機能**
   - 総合ポイント獲得数によるリーダーボード（上位5名を表示）
   - ※デモデータはランキングから除外される

6. **バッジ・実績機能**
   - 走行距離、CO2削減量、ポイント、アクティビティ回数に応じたバッジ付与

7. **デモモード機能**
   - Strava API未承認や未連携のユーザーでも、ボタン一つでダミーデータを生成し、全機能を体験できる機能
   - **動作確認用アカウント**:
     - メールアドレス: `test+clerk_test@example.com`
     - パスワード: `EcoMiles2026!`
     - 検証コード: `424242`

8. **シェア機能**
   - 自身の貢献（ポイント、CO2削減量など）をカード形式で画像として表示し、SNS等で共有するためのモーダル表示

### 2.2 追加機能（将来的な拡張）
1. **コミュニティ機能**
   - フォロー機能、アクティビティ共有、コメント/いいね

2. **チャレンジ機能**
   - 期間限定ミッション、グループチャレンジ

## 3. 非機能要件

### 3.1 ユーザビリティ
- レスポンシブデザイン（モバイル/デスクトップ最適化）
- ダークモード対応
- 直感的なデータ可視化（アニメーション、ヒートマップ）

### 3.2 パフォーマンス
- サーバーサイドレンダリング（SSR）とクライアントサイド更新の組み合わせによる高速表示
- 追加読み込み（無限スクロール形式）による履歴表示の最適化

### 3.3 セキュリティ
- Clerkによる安全なアイデンティティ管理
- Strava OAuthの適切なトークン管理（暗号化、自動リフレッシュ）
- 日本時間（Asia/Tokyo）に統一したデータ集計

## 4. システム構成

### 4.1 開発環境
- フロントエンド/バックエンド：Next.js (App Router) / TypeScript
- スタイリング: Tailwind CSS / Framer Motion (アニメーション)
- データベース：Supabase (PostgreSQL)
- ORM: Prisma
- 認証：Clerk

### 4.2 外部連携
- Strava API (OAuth 2.0)
